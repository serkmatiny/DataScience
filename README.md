## 📖 เนื้อหาทั้งหมด

### 📘 [ส่วนที่ 1: พื้นฐาน (Beginner)](./Data_Science_Teaching_Guide_2025.md)

เหมาะสำหรับ: มือใหม่ที่เริ่มต้นเรียน Data Science

**เนื้อหา:**
1. Data Science คืออะไร?
2. ติดตั้งและเตรียมสภาพแวดล้อม (Python, Libraries)
3. Python สำหรับ Data Science
   - Variables, Data Types, Lists, Dictionaries
   - Loops, Conditions, Functions
   - List Comprehension
4. NumPy และ Pandas พื้นฐาน
   - Arrays และ Operations
   - DataFrames และ Data Manipulation
5. Data Visualization
   - Matplotlib, Seaborn, Plotly

**เวลาเรียน:** 2-3 สัปดาห์

---

### 📙 [ส่วนที่ 2: ระดับกลาง (Intermediate)](./Data_Science_Intermediate_2025.md)

เหมาะสำหรับ: ผู้ที่มีพื้นฐาน Python และ Data Analysis แล้ว

**เนื้อหา:**
6. Exploratory Data Analysis (EDA)
   - ทำความเข้าใจข้อมูล
   - Visualizations สำหรับ EDA
7. Data Preprocessing และ Feature Engineering
   - จัดการ Missing Data และ Outliers
   - Encoding Categorical Variables
   - Scaling และ Normalization
   - สร้าง Features ใหม่
8. Machine Learning พื้นฐาน
   - Linear Regression
   - Logistic Regression
   - Decision Tree
9. Machine Learning ขั้นสูง
   - Random Forest
   - Gradient Boosting (XGBoost, LightGBM, CatBoost)
10. AutoML ในปี 2025
    - PyCaret
    - Optuna

**เวลาเรียน:** 3-4 สัปดาห์

### 📕 [ส่วนที่ 3: ระดับสูง (Advanced)](./Data_Science_Advanced_2025.md)

เหมาะสำหรับ: ผู้ที่ต้องการความรู้ขั้นสูงและเทคโนโลยีล่าสุด

**เนื้อหา:**
11. Deep Learning และ Neural Networks
    - PyTorch Framework
    - CNN สำหรับภาพ
12. Generative AI และ LLMs
    - Hugging Face Transformers
    - Text Generation, Sentiment Analysis
    - Question Answering, Summarization
13. Agentic AI
    - Autonomous Agents
    - Multi-Agent Systems
14. Real-time Data Science
    - Dask Parallel Processing
    - Stream Processing
    - Real-time Monitoring
15. Edge AI และ IoT
    - Model Optimization (Pruning, Quantization)
    - Edge Deployment
    - IoT Sensor Processing
16. Green AI และ Ethical AI
    - Energy-Efficient Training
    - Carbon Footprint Estimation
    - Fairness Analysis และ Bias Mitigation
17. Deployment และ Production AI
    - FastAPI ML APIs
    - Docker Containers
    - Model Monitoring

**เวลาเรียน:** 4-6 สัปดาห์

## 🌟 เทคโนโลยีและเทรนด์ในปี 2025

คู่มือนี้ครอบคลุมเทคโนโลยีล่าสุด:

### 🤖 AI & Machine Learning
- ✅ **Agentic AI** - AI ที่ทำงานอัตโนมัติ
- ✅ **Small Language Models (SLMs)** - โมเดลขนาดเล็กแต่ทรงพลัง

- ✅ **Generative AI** - สร้างเนื้อหาด้วย AI

### ⚡ Real-time & Edge
- ✅ **Real-time Data Science** - วิเคราะห์แบบทันที
- ✅ **Edge AI** - AI บน device
- ✅ **IoT Integration** - เชื่อมต่อกับ IoT

### 🌱 Sustainability & Ethics
- ✅ **Green AI** - ประหยัดพลังงาน 50%
- ✅ **Ethical AI** - AI ที่ยุติธรรม
- ✅ **Explainable AI** - อธิบายได้ชัดเจน

### 🚀 Production & Deployment
- ✅ **FastAPI** - API สำหรับ ML
- ✅ **Docker** - Container deployment
- ✅ **Model Monitoring** - ติดตามโมเดลในการใช้งานจริง

## 🎯 Career Path

### Junior Data Scientist (0-2 ปี)
**ต้องรู้:**
- Python, SQL
- Pandas, NumPy
- Basic ML (Scikit-learn)
- Data Visualization

**เงินเดือน:** 25,000 - 45,000 บาท

### Mid-Level Data Scientist (2-5 ปี)
**ต้องรู้:**
- Advanced ML
- Deep Learning พื้นฐาน
- A/B Testing
- Cloud platforms (AWS/GCP)

**เงินเดือน:** 50,000 - 100,000 บาท

### Senior Data Scientist (5+ ปี)
**ต้องรู้:**
- Advanced Deep Learning
- MLOps
- Architecture Design
- Team Leadership

**เงินเดือน:** 100,000 - 200,000+ บาท
